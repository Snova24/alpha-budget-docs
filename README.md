# Public policy pages (GitHub Pages)

After pushing this repo to GitHub, enable Pages:

1. Repo **Settings → Pages**
2. Source: **Deploy from branch**
3. Branch: **master** (or **main**), folder: **/docs**
4. Save

Your privacy URL for Play Console:

`https://YOUR_GITHUB_USERNAME.github.io/REPO_NAME/privacy.html`

Replace `YOUR_GITHUB_USERNAME` and `REPO_NAME` with your actual values.
